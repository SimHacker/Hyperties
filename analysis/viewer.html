How to explore and what to look for

As in HyperTIES: click a highlighted link to see its short description; double-click it (or press Follow link) to go there. With the keyboard, Tab to a link and press Enter once to see its description, twice to follow. Browser Back retraces your path. Search includes original aliases. Dotted labels indicate destinations we have not resolved.

Original prose is not rewritten. The reading view can hide command tokens for readability; the original byte-view text and source checksums remain below each article. Graphics, fonts, exact page layouts and the remaining codec are still research work. This is not the original DOS interface.

We would especially value your memories of the joke's authorship and first demonstration, the book's exact edition, and how the museum's thematic, chronological and map navigation worked.

Recovery status and interpretation

Research prototype, not an emulation of the original interface. Classic text is displayed using an explicit CP437 access profile; historical encoding is still under investigation. Graphics, fonts and commands are not executed. Missing records and uncertain links remain visible. The separate personal genealogy database is not included in this reading room, and this file contains no Dropbox access link or credentials.
